# Steal An Egg 화면 배치 참고 / v0.3

이번 버전은 기존의 임의 건물형 맵을 폐기하고 실제 플레이 스크린샷에서 보이는 구조를 참고해 재구성했습니다. Roblox 원본 프로젝트나 맵 치수 자료를 확보한 것은 아니므로 **원본과 픽셀·치수·기능이 완전히 동일한 복제본은 아닙니다.**

## 참고한 실제 화면

- [펫 구역과 HUD — BO3](https://bo3.gg/games/articles/steal-an-egg-pets-guide)
- [기지·울타리·격자 지형 — BO3](https://bo3.gg/games/articles/steal-an-egg-gamepasses-guide)
- [넓은 맵과 안전 구역 — SuperCheats](https://www.supercheats.com/steal-an-egg-codes)

참고 이미지는 저장소에 배포하지 않습니다. 게임에 포함된 모델·아이콘·지형 셰이더는 이 프로젝트에서 작성했습니다. 인터페이스 폰트의 라이선스는 `Godot/assets/fonts/LICENSE.txt`에 있습니다.

## 현재 구성

| 항목 | 구현 |
| --- | --- |
| 화면 기준 | 1920×1080 논리 해상도, 기본 창 1280×720, 최소 창 960×540 |
| 창/전체화면 | 창 크기 변경 가능, F11 전체화면 전환 |
| HUD | 왼쪽 중앙 Shop/Index/Slow Mode, 왼쪽 아래 속도/재화, 아래 중앙 10슬롯, 오른쪽 탭, 오른쪽 위 로컬 통계 |
| 맵 바닥 | 192×320 Godot 단위, 바닥 스터드 간격 0.45 단위 |
| 외곽벽 | 높이 18 단위, 스터드/체커 표면 |
| 기본 펫 구역 | 42×38 단위, 열린 입구와 나무 교차 울타리 |
| 구역 | Forest, Lake, Desert, Jungle, Snow 순서의 지형 5개 |
| 카메라 | FOV 70°, 기본 거리 9, 휠로 5~45 조절, RMB 회전 |
| 동작 메뉴 | Shop에서 재화로 속도/기지 구매, Index/Pets 보유 수 확인, Eggs 운반 상태 확인, Settings 조작법/전체화면 |
| Slow Mode | 기본 이동 속도로 전환 |
| 펫 | Chicken, Cat, Crocodile, Dragon, Fox, Mammoth, 이전보다 큰 월드 표시 |

5개 구역은 지형 및 탐험 공간이며, 각 구역마다 독립적인 수호 동물이나 성장 경제를 모두 구현한 것은 아닙니다. 현재 핵심 시스템은 숲 수호 동물의 추격, 알 운반, 부화, 수익, 강화, 저장입니다. 멀티플레이는 포함하지 않습니다. 오른쪽 위 통계는 현재 로컬 플레이어의 실제 데이터입니다.

펫 재화 표시와 메뉴 배치는 원본 화면을 참고했지만, 가격·성장 속도·펫 종류·맵 치수는 이 프로젝트의 값입니다. 스크린샷 촬영 모드는 저장 데이터를 건드리지 않고 6마리 펫이 있는 장면을 구성합니다.
